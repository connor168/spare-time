# WeChat Open Platform review assets

These files are prepared for the Focus Flow Android mobile-app registration.

## Upload order

1. High-definition application image:
   `../branding/focus-flow-wechat-108.png`
2. Application operation flow:
   `focus-flow-app-operation-flow.png`
3. Planned WeChat-login flow:
   `focus-flow-wechat-login-flow.png`

Both flow diagrams are 1600 x 1200 PNG files and remain below the platform's
5 MB per-image limit. The editable HTML/CSS sources live under `source/`.

The WeChat-login diagram deliberately says that the integration is enabled
after approval. Do not present the login feature as already available in the
preview APK until the OpenSDK and server-side exchange are implemented.
