Focus Flow · APP 核心运行流程

学生时间管理、任务提醒与科技资讯聚合
Android 个人测试版
1

建立今日计划

从课程、作业、考试与个人目标中整理任务；也可手动新建时间段。

课程 + 任务
2

生成计划草稿

根据当天已有安排寻找空闲时间，先形成草稿，由用户调整时长和顺序。

确认后生效
3

按时间执行

任务开始前默认 5 分钟提醒；时间线展示当前时段应该完成的内容。

本地通知
4

记录完成结果

已完成即勾选；未完成任务只在当天尝试重排，否则保留为“今日未完成”。

保留历史

科技资讯流程

  • 每日 07:00 更新 GitHub 热门、AI、科技与 Linux 资讯
  • 手机仅收到一条“今日资讯已更新”通知
  • 进入列表后阅读约 50 条内容，并可在英文原文与本地中文翻译间切换

账号与数据流程

  • 游客可先在本机使用课程、任务和笔记功能
  • 登录后将计划数据同步到个人账号，供多设备继续使用
  • 微信登录在开放平台审核通过后接入，密钥仅保存在服务端
隐私原则：仅在功能需要时申请通知、文件导入等权限；账号数据支持导出与删除。 Focus Flow / com.focusflow.planner
