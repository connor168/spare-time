# Focus Flow brand assets

The permanent app icon combines a flowing clock with a completion check mark.
Its primary color is `#157A6E`, matching the Material theme used by the app.

- `focus-flow-icon-master.png`: editable-quality raster master generated for this project.
- `focus-flow-store-512.png`: app-store and general listing icon.
- `focus-flow-wechat-108.png`: WeChat Open Platform large icon.
- `focus-flow-wechat-28.png`: WeChat Open Platform basic-information icon.

Run `scripts/export_brand_assets.py` with a Python environment containing Pillow
after replacing the master. The script also updates the Android launcher icons
and the website copy.

Do not change the icon in only one channel. The APK, website, app-store listing,
WeChat registration, and QQ registration must continue to use the same design.
