# 设备兼容与测试矩阵

## 布局矩阵

| 窗口宽度 | 导航 | 内容布局 | 必测状态 |
|---|---|---|---|
| `<600dp` | 底部导航 | 单栏 | 小屏手机、字体放大、竖屏 |
| `600-840dp` | NavigationRail | 双栏能力 | 大屏手机、小平板、分屏 |
| `>840dp` | NavigationRail | 双/三栏能力 | Android 平板、iPad 横屏、折叠屏展开 |

## 平台矩阵

| 平台 | MVP 目标 | 通知验证 | 资讯推送 |
|---|---|---|---|
| Android 手机 8+ | 支持 | 权限、Doze、重启、精确闹钟 | FCM |
| Android 平板 8+ | 支持 | 横竖屏、后台、重启 | FCM |
| iPhone iOS 15+ | 支持 | 权限、锁屏、通知点击 | APNs |
| iPad iPadOS 15+ | 支持 | 横竖屏、Split View | APNs |
| 华为无 GMS | 本地功能支持 | 本地通知与电量优化 | HMS 完成前不承诺 |
| 折叠屏 | 响应式支持 | 展开/收起时重排 | 依系统服务 |

## 每次发布前的场景

- 离线创建、编辑、完成任务和笔记。
- 锁屏、杀进程、设备重启后的提醒。
- 修改时区、系统时间和夏令时边界。
- 横竖屏切换、iPad 分屏、Android 多窗口。
- 字号放大、TalkBack/VoiceOver、键盘焦点和触控目标。
- 通知权限拒绝、永久拒绝、重新开启。
- GitHub API 429、超时、空结果和缓存回退。
- 双设备离线编辑后恢复网络。
