一天，不需要靠记忆硬撑。

课程表提供固定边界，任务和目标填入空闲时间；每次自动调整都先让你确认。

01

今日时间线

课程、任务和个人安排集中在一条时间线上，默认提前五分钟提醒。

02

计划草稿

根据课程、作业、考试和目标生成规则化草稿；你决定时长和是否生效。

03

当日再安排

未完成任务只寻找当天空闲时间，不挤占第二天；当天结束后保留为“今日未完成”。

04

科技资讯

聚合 GitHub 热点及 AI、科技、Linux RSS，早上七点只发送一条更新通知。

05

中英切换

保留英文原文，并计划使用 Android 本地翻译能力显示中文，减少云端数据传输。

06

账号与同步

登录后同步计划、任务和笔记；离线时仍可使用本地数据，联网后手动同步。
